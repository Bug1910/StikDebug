# 第 8 章：疑難排解

**重點**：發生問題時，請先記下畫面上的**文字**與**錯誤代碼**（括號內的數字或英文），再依下表處理。多數問題來自 LocalDevVPN 未連線、Wi-Fi 未連上，或 Apple 暫時拒絕登入。

## 8.1 處理原則

1. 記下畫面上的文字與錯誤代碼。
2. 確認 Wi-Fi 已連上，LocalDevVPN 已開啟（第 4 章）。
3. 1 至 2 分鐘後重試。
4. 請勿連續重試。短時間內多次登入會遭 Apple 暫時拒絕。
5. 仍失敗時，改用電腦重新安裝（見 8.3），或數小時後再試。

## 8.2 無法前往地點

| 畫面文字 | 錯誤代碼 | 處理方式 |
|---|---|---|
| 尚未配對 | 無 | 依第 3 章產生並匯入配對檔 |
| 無法連線至手機的定位服務 | 3 或 9 | 確認 Wi-Fi 已連上、LocalDevVPN 已連線後重試 |
| 未連上 Wi-Fi | 3 或 9 | 連上 Wi-Fi，或依第 4 章 4.5 的步驟操作 |
| 開發者映像未掛載 | 10 | 在 `設定 › 進階 › 開發者映像（DDI）` 點選 `掛載`。第一次會下載約數十 MB，需要 LocalDevVPN 已連線 |
| 模擬位置無法送至手機 | 11 | 解鎖手機後重試 |
| 無法清除手機上的模擬位置 | 12 | 解鎖手機並確認 LocalDevVPN 已連線，再點選「停止模擬」 |
| 定位失敗 | 其他數字 | 確認 LocalDevVPN 已連線、開發者映像已掛載後重試 |
| 目標 IP 錯誤 | 1 | 在首頁提示列點選 `改回預設`；或在 `設定 › 進階 › 除錯工具` 將 IP 改回 `10.7.0.1` |

### 定位權限

無法模擬或切換 App 後模擬停止時，請至 iPhone 的 `設定 › PinFly › 位置` 開啟位置權限。 〔待確認：權限選項的確切文字〕

## 8.3 續簽時的錯誤

| 畫面標題 | 錯誤代碼 | 說明與處理 |
|---|---|---|
| Apple 拒絕此次登入 | -80045、-80046 | 數小時後再試，避免連續重試。 〔待確認：Apple 目前拒絕此類登入的政策〕 |
| Apple 或驗證伺服器暫時無法使用 | 503 | 伺服器忙碌或維護中，請稍後再試。 |
| Apple 開發者服務回傳錯誤 | 1100 | 驗證伺服器回應過慢時發生，App 已自動重試 1 次。請數分鐘後再試。 |
| 驗證伺服器回應逾時 | 無 | 伺服器未及時回應，App 會自動重試。請更換網路或稍後再試。 〔待確認：等待秒數門檻，App 內不同畫面寫法不同：6 秒、16 秒、30 秒〕 |
| 無法連線至驗證伺服器 | 無 | 請稍後再試。 |
| 沒有網路連線 | 無 | 連上 Wi-Fi 或行動網路後再試。 |
| Apple ID 或密碼不正確 | -22406 | 重新輸入。 |
| 此帳號需使用 App 專用密碼 | -20101 | 至 appleid.apple.com 產生「App 專用密碼」，再以此密碼登入。 |
| 驗證碼不正確 | -21669 | 重新輸入收到的 6 位數驗證碼。 |
| 嘗試次數過多 | -21668 | Apple 暫時限制登入，請數小時後再試。 |
| 尚未登入 Apple ID | 無 | 在 `設定 › 簽名` 登入。 |
| 登入已過期 | 無 | 重新登入並輸入新的驗證碼。 |
| 此 Apple ID 與安裝 PinFly 的帳號不同 | 無 | 改用安裝 PinFly 時的 Apple ID 登入。 |
| Apple 帳號中找不到 PinFly 的 App ID | 無 | App 不會自動建立，請用電腦（iloader）重新安裝 PinFly。 |
| 本週 Apple 帳號的 App ID 數量已用完 | 無 | 免費 Apple ID 每 7 天最多 10 個 App ID。請於恢復後再試，或用電腦重新安裝。 〔待確認：恢復時間〕 |
| 此手機尚未登記至 Apple 帳號 | 無 | 以 iloader 安裝 PinFly，即可完成登記。 |
| 新描述檔的憑證與目前的 App 不同 | 無 | 安裝後 App 將無法開啟，因此未安裝。請用電腦重新安裝。 |
| 描述檔已下載，尚未安裝 | 無 | 依第 5 章 5.7，連線 LocalDevVPN 後點選「安裝」。 |
| 登入成功，但無法儲存登入資料 | keychain | PinFly 無法將登入資料存入鑰匙圈。請重新安裝 PinFly 後再試。 |
| 續簽失敗 | 其他數字 | 稍後再試；持續失敗時請用電腦重新安裝。 |

### 用電腦重新安裝（備用方法）

App 內續簽持續失敗時，可用電腦（iloader）重新安裝 PinFly，地點不會刪除。 〔待確認：完整步驟，與第 2 章 2.2 相同〕

## 8.4 進階頁的工具（一般不需要）

在 `設定 › Apple 帳號與續簽 › 進階` 可以：

- 測試驗證伺服器的速度，並改選伺服器。
- 匯入描述檔。
- 清除過期的描述檔。
- 重設驗證資料（adi.pb）。

僅在續簽持續失敗時才需要變更此頁設定。

## 8.5 回報問題時請附上

- iPhone 型號與 iOS 版本（`設定 › 一般 › 關於本機`）。
- 畫面上的完整文字與錯誤代碼。
- 發生時間，以及當時使用 Wi-Fi 或行動網路。
- `續簽紀錄` 中對應的紀錄。 〔待確認：是否有可匯出的診斷紀錄〕

請勿在回報中附上 Apple ID 密碼、驗證碼或配對檔內容。
