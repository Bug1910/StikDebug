# 第 8 章：疑難排解

**先看這裡**：遇到問題時，先記下畫面上的**文字**與**錯誤代碼**（括號裡的數字或英文），再依下表查。大部分問題是 LocalDevVPN 沒開、Wi-Fi 沒連、或登入 Apple 被暫時擋住。

## 8.1 處理原則

1. 先看畫面上的文字，記下錯誤代碼。
2. 確認 Wi-Fi 已連上，LocalDevVPN 已開啟（第 4 章）。
3. 等 1 到 2 分鐘再試一次。
4. 不要連續一直重試。Apple 會因為短時間多次登入而暫時擋住。
5. 仍然失敗時，依 8.4 的方法改用電腦續簽，或再等幾個小時。

## 8.2 定位送不出去

| 畫面文字 | 錯誤代碼 | 怎麼做 |
|---|---|---|
| 還沒配對 | 無 | 依第 3 章產生並匯入配對檔 |
| 連不到手機的定位服務 | 3 或 9 | 確認 Wi-Fi 已連上，LocalDevVPN 已連線，再按一次 |
| 沒有連上 Wi-Fi | 3 或 9 | 連上 Wi-Fi，或依第 4 章 4.5 的 4G 步驟操作 |
| 定位服務打不開，多半是開發者磁碟映像（DDI）還沒掛載 | 10 | 到 `設定 → 進階 → 開發者映像（DDI）`，按 `掛載 DDI`。第一次會下載約數十 MB，需要 LocalDevVPN 已連線 |
| 位置送不進手機 | 11 | 解鎖手機，再按一次 |
| 沒能清掉手機上的模擬定位，手機可能還停在假的位置 | 12 | 解鎖手機，確認 LocalDevVPN 已連線，再按一次「停止模擬」 |
| 定位失敗 | 其他數字 | 確認 LocalDevVPN 已連線、DDI 已掛載，再試 |
| 目標 IP 設定錯誤 | 1 | 首頁提示列按 `改回預設`；或到 `設定 › 進階：原始除錯工具` 將 IP 改回 `10.7.0.1` |

### 定位權限

如果地點無法模擬，或切到其他 App 就停止，請到 iPhone 的 `設定 → PinFly → 位置`，把權限打開。 〔待確認：權限選項的確切文字〕

## 8.3 續簽時的錯誤

| 畫面標題 | 錯誤代碼 | 意思與處理 |
|---|---|---|
| Apple 拒絕這次登入 | -80045、-80046 | Apple 暫時擋下這類工具的登入。隔幾小時再試，不要連續重試。 〔待確認：Apple 目前的擋登入政策〕 |
| Apple 或驗證伺服器暫時不能用 | 503 | 對方伺服器忙或維修中。過一段時間再按。 |
| Apple 開發者服務回 1100 | 1100 | 驗證伺服器太慢時可能出現。App 會自動重試 1 次，仍失敗就過幾分鐘再按。 |
| 驗證伺服器太慢 | 無 | 伺服器沒有及時回應，App 會自動重試。換個網路或稍後再試。 〔待確認：等待秒數門檻，App 內不同畫面寫法不同：6 秒、16 秒、30 秒〕 |
| 連不上驗證伺服器 | 無 | 稍後再試。 |
| 網路不通 | 無 | 確認手機有網路（Wi-Fi 或 4G）後再試。 |
| Apple ID 或密碼不對 | -22406 | 重新輸入。 |
| 這個帳號要用 App 專用密碼 | -20101 | 到 appleid.apple.com 產生「App 專用密碼」，用它登入。 |
| 驗證碼不對 | -21669 | 再輸入一次收到的 6 位數。 |
| 嘗試次數太多 | -21668 | Apple 暫時不讓再試，等幾小時。 |
| 還沒登入 Apple ID | 無 | 到 `設定 → 簽名` 登入一次。 |
| 登入已過期 | 無 | 重新登入，會再收到一次驗證碼。 |
| 這個 Apple ID 不是簽這個 App 的帳號 | 無 | 改用安裝 PinFly 時的 Apple ID 登入。 |
| Apple 帳號裡找不到 PinFly 的 App ID | 無 | App 不會自己新增，請用電腦（iloader）續簽一次。 |
| 這週 Apple 帳號能簽的數量用完了 | 無 | 免費 Apple ID 每 7 天最多 10 個 App ID。到期後再試，或用電腦續簽。 〔待確認：恢復時間〕 |
| 這支手機還沒登記到 Apple 帳號 | 無 | 用 iloader 裝一次 PinFly，手機就會登記。 |
| 新簽名的憑證和 App 現在用的不同 | 無 | App 會打不開，因此已停止，什麼都沒裝。請用電腦續簽。 |
| 新簽名已下載，還沒裝上 | 無 | 依第 5 章 5.7 的做法，連上 LocalDevVPN 後按「裝上」。 |
| 登入成功，但存不了登入資料 | keychain | 這支手機不讓 PinFly 把登入資料存進鑰匙圈。請重新安裝 PinFly 後再試。 |
| 續簽失敗 | 其他數字 | 稍後再試；一直失敗就用電腦續簽。 |

### 用電腦續簽（備用方法）

當 App 內續簽一直失敗時，可以用電腦（iloader）重新安裝一次 PinFly。 〔待確認：完整步驟，與第 2 章 2.2 相同〕

## 8.4 進階頁的工具（一般不用）

在 `設定 → Apple 帳號與續簽 → 進階（一般不用改）`，可以：

- 測試驗證伺服器的速度，並改選伺服器。
- 匯入描述檔（不用重裝）。
- 清掉過期的舊描述檔。
- 重設驗證資料（adi.pb）。

只有在續簽一直失敗、並且 App 的說明要求時，才需要動這一頁。

## 8.5 回報問題時請附上

- iPhone 型號與 iOS 版本（`設定 → 一般 → 關於本機`）。
- 畫面上的完整文字與錯誤代碼。
- 發生的時間，以及是否在 Wi-Fi 或只有 4G。
- `續簽紀錄` 中對應的那一筆。 〔待確認：是否有可匯出的診斷紀錄〕

不要在回報中附上 Apple ID 密碼、驗證碼或配對檔內容。
