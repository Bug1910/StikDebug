# 第 3 章：配對檔

**重點**：配對檔讓 PinFly 能連線至此 iPhone，只需以電腦產生一次並匯入 PinFly。首頁顯示「尚未配對」時，表示尚未匯入。

## 3.1 配對檔是什麼

| 詞 | 說明 |
|---|---|
| 配對檔 | 記錄電腦與此 iPhone 連線資訊的檔案 |
| 副檔名 | `.plist` 或 `.mobiledevicepairing`（PinFly 接受這兩種） |
| 有效期 | 變更 iPhone 密碼或重設手機後，配對檔會失效，需重新產生 〔待確認：以 iloader 說明為準〕 |

配對檔僅適用於產生時連接的 iPhone，無法用於其他手機。

## 3.2 產生配對檔（在電腦上操作）

1. 確認 iTunes 已安裝（第 1 章）。
2. 以 USB 傳輸線連接 iPhone 與電腦。
3. 在 iPhone 的「信任這部電腦」提示點選「信任」，並輸入密碼。 〔待確認：畫面文字〕
4. 開啟 iloader。
5. 點選 `Manage Pairing File`（管理配對檔）。 〔待確認：按鈕文字〕
6. 在 PinFly（或 StikDebug，依 App 名稱顯示）那一列，點選 `Place`（放置）。
7. 看到綠色的「Pairing file placed successfully!」（配對檔放置成功）即完成。 〔待確認：PinFly 是否需要另外匯入〕

## 3.3 將配對檔匯入 PinFly（在 iPhone 上操作）

iloader 放置後，PinFly 首頁仍顯示「尚未配對」時，請手動匯入：

1. 將配對檔存至 iPhone 的「檔案」App（以 AirDrop 或電腦傳輸）。 〔待確認：傳輸方式〕
2. 開啟 PinFly，點選右上角的 `設定`（齒輪圖示）。
3. 點選 `進階`。
4. 找到 `配對檔` 這一區，點選 `匯入配對檔`。
5. 出現「覆蓋現有配對檔？」時，點選 `選擇新的配對檔`。
6. 在檔案列表中選擇配對檔。
7. 看到「配對檔已匯入。」即完成。

## 3.4 開發者模式

開發者模式在第 2 章 2.5 開啟（需在安裝 PinFly 之後、使用 PinFly 之前）。尚未開啟時，請先回到 2.5。

## 3.5 完成檢查

- 首頁的「尚未配對」提示消失，表示配對檔已生效。
- 提示仍顯示時，請依 3.3 重新匯入。

> 注意：請勿公開分享或上傳配對檔，持有配對檔即可連線至此手機。
