# 第 3 章：配對檔與開發者模式

**先看這裡**：配對檔是讓 PinFly 認得你的 iPhone 的「鑰匙」。只要用電腦產生一次，匯入 PinFly 後就能使用。首頁出現「還沒配對」時，代表還沒匯入。

## 3.1 配對檔是什麼

| 詞 | 白話說明 |
|---|---|
| 配對檔 | 一個檔案，記錄電腦與這支 iPhone 的連線資訊 |
| 副檔名 | `.plist` 或 `.mobiledevicepairing`（PinFly 接受這兩種） |
| 有效期 | 你變更 iPhone 的密碼（passcode）或重設手機後，配對檔會失效，要重新產生 〔待確認：以 iloader 說明為準〕 |

配對檔只跟這一支 iPhone 有關，不能拿去別人的手機用。

## 3.2 產生配對檔（在電腦上做）

1. 確認 iTunes 已安裝（第 1 章）。
2. 用 USB 傳輸線把 iPhone 接到電腦。
3. 在 iPhone 上按「信任這台電腦」，並輸入密碼。 〔待確認：畫面文字〕
4. 打開 iloader。
5. 按 `Manage Pairing File`（管理配對檔）。 〔待確認：按鈕文字〕
6. 在 PinFly（或 StikDebug，依 App 名稱顯示）那一列，按 `Place`（放置）。
7. 看到綠色的「Pairing file placed successfully!」（配對檔放置成功）即完成。 〔待確認：PinFly 是否需要另外匯入〕

## 3.3 把配對檔匯入 PinFly（在 iPhone 上做）

如果 iloader 放置後，PinFly 首頁仍顯示「還沒配對」，請用手動匯入：

1. 先把配對檔存到 iPhone 的「檔案」App 裡（用 AirDrop 或電腦傳輸）。 〔待確認：傳輸方式〕
2. 打開 PinFly，按右上角的 `設定`（齒輪圖示）。
3. 點選 `進階（一般不用動）`。
4. 找到 `配對檔（連手機用的鑰匙）` 這一區，按 `匯入配對檔`。
5. 如果出現「覆蓋現有配對檔？」，確認覆蓋。
6. 在檔案列表中選擇配對檔。
7. 看到「配對檔已匯入。」即完成。

## 3.4 開發者模式

PinFly 的定位功能可能需要 iPhone 的「開發者模式」。 〔待確認：是否所有 iOS 版本都需要、開啟的確切路徑〕

1. 打開「設定」。
2. 點選「隱私與安全性」。
3. 往下找到「開發者模式」，打開它。
4. 依畫面指示重新開機，並確認。

![](images/ch03-05.png)

*截圖說明：「設定 → 隱私與安全性」頁面，標出「開發者模式」開關。 〔待確認：為實際截圖〕*

## 3.5 完成檢查

- 首頁的「還沒配對」提示消失，代表配對檔已生效。
- 如果還在，請回到 3.3 重新匯入。

> 注意：配對檔不要公開分享、不要上傳到網路。它等同於這支手機的連線鑰匙。
