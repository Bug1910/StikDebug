# 第 5 章：登入 Apple 與自動續簽

**先看這裡**：免費 Apple ID 簽的 App 每 7 天到期。到期前在 PinFly 裡登入一次 Apple ID，之後 PinFly 就能自己換新的 7 天簽名。續簽只換簽名，**地點不會不見**。

## 5.1 名詞

| 詞 | 白話說明 |
|---|---|
| 簽名到期 | App 的 7 天期限。到期後 App 會打不開 |
| 驗證碼 | Apple 傳到你信任的裝置上的 6 位數字 |
| 驗證伺服器（anisette） | 協助登入 Apple 的公開伺服器，用來產生「這台裝置」的驗證資料。它**不會收到**你的 Apple ID 或密碼 |
| 鑰匙圈（Keychain） | iPhone 內建的加密保險箱，用來存放登入資料 |

## 5.2 第一次登入 Apple

1. 打開 PinFly，按右上角 `設定`（齒輪）。
2. 在「簽名」區，按 `登入 Apple` 或 `登入並續簽`。
3. 在第 1 步（1/3）閱讀說明，按 `下一步`。
4. 在第 2 步（2/3），輸入 Apple ID，再輸入密碼。
5. 按 `登入`。
6. 等待畫面顯示「登入 Apple（3／3）」。
7. 在 iPhone 上看到 Apple 傳來的 6 位數驗證碼，輸入到 PinFly。
8. 輸入第 6 碼時會自動送出，也可以按 `送出驗證碼`。
9. 畫面顯示「已登入」後，按 `立即續簽` 或 `完成`。

App 內的說明寫明：Apple ID 與密碼只存在這支 iPhone 的鑰匙圈，只送給 Apple。 〔待確認：獨立安全審查結果〕

> Apple ID 要用**安裝 PinFly 時用的那一個**。用別的 Apple ID 登入會顯示「這個 Apple ID 不是簽 PinFly 的帳號」。

## 5.3 立即續簽

續簽有四個步驟，畫面會逐一顯示：

| 步驟 | 畫面文字 | 白話說明 |
|---|---|---|
| 1 | 連到驗證伺服器 | 連上協助登入的公開伺服器 |
| 2 | 登入 Apple | 用你的 Apple ID 登入 |
| 3 | 取得新的 7 天簽名 | 向 Apple 要一份新的簽名 |
| 4 | 裝到這支手機 | 把新簽名裝上 iPhone |

1. 打開 PinFly，按 `設定`。
2. 在「簽名」區，按 `立即續簽`。
3. 等待四個步驟都顯示完成。
4. 看到「成功，到 MM/dd HH:mm」的字樣即完成。

![](images/ch05-04.png)

*截圖說明：續簽進行中，四個步驟的進度列表，已完成的步驟打勾。*

## 5.4 自動續簽

PinFly 可以在你打開 App 時，自動續簽。

1. 打開 `設定`。
2. 點選 `Apple 帳號與續簽`。
3. 打開 `自動續簽` 開關。

規則：打開 PinFly 時，如果簽名剩不到 **3 天**，就會自動續簽；每 **6 小時**最多試一次。若 Apple 暫時不讓登入，會等 6 小時再試。

## 5.5 首頁的剩餘天數

首頁上方的狀態列會顯示簽名還剩幾天。

- 剩 3 天以上：不會特別提醒。
- 剩 2 天以內：按鈕會變成明顯的綠色「立即續簽」。
- 剩不到 3 小時：首頁提示列會出現「續簽」按鈕，一按即可。

## 5.6 續簽紀錄

在 `Apple 帳號與續簽` 頁面，可以看到「續簽紀錄（最近 5 筆）」，每一筆寫明成功或沒成功，以及原因。出問題時，請把這裡的時間與原因記下來，第 8 章會用到。

## 5.7 4G 情況下的續簽

續簽分成兩段，是為了讓只有 4G 的人也能完成：

- **下載**：要有網路（4G 可以），不需要 LocalDevVPN。
- **安裝**：要 LocalDevVPN 已連線。

安裝時的操作依網路狀態不同：

| 情況 | 怎麼做 |
|---|---|
| 有 Wi-Fi | 開 LocalDevVPN，回到 PinFly，按 `裝上` 或 `裝上新簽名` |
| 只有 4G | 關閉行動數據 → 開 LocalDevVPN → 按 `裝上新簽名` → 裝好後再開回行動數據 |

App 內說明寫的是「關閉行動數據」。 〔待確認：以「飛航模式＋Wi-Fi」完成安裝是否可行，請實機確認後再寫入本教學〕

如果安裝沒完成，畫面會顯示「新簽名已下載，還沒裝上」。這時不需要重新下載或重新登入，依上面的步驟再裝一次即可。

## 5.8 登出與重設（一般不用做）

- `登出 Apple 帳號`：登出後要重新輸入密碼與驗證碼。登出後若 Apple 擋住登入，到期後 App 會打不開。
- `重設驗證資料（adi.pb）`：只有在 Apple 一直要求重新驗證時才需要。重設後要重新登入一次。

> 在做這兩件事之前，先確認你知道目前的 Apple ID 與密碼。
