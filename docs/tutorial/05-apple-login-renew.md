# 第 5 章：登入 Apple 與自動續簽

**重點**：以免費 Apple ID 簽名的 App 每 7 天到期。在 PinFly 登入 Apple ID 後，PinFly 即可自動續簽 7 天簽名。續簽**不會刪除地點**。

## 5.1 名詞

| 詞 | 說明 |
|---|---|
| 簽名到期 | App 的 7 天使用期限。到期後 App 無法開啟 |
| 驗證碼 | Apple 傳送至受信任裝置的 6 位數字 |
| 驗證伺服器（anisette） | 協助登入 Apple 的第三方公開伺服器，用於產生裝置驗證資料，**不會收到** Apple ID 或密碼 |
| 鑰匙圈（Keychain） | iPhone 內建的加密儲存區，用於存放登入資料 |

## 5.2 第一次登入 Apple

1. 開啟 PinFly，點選右上角 `設定`（齒輪）。
2. 在「簽名」區，點選 `登入 Apple` 或 `登入並續簽`。
3. 在第 1 步（1/3）閱讀說明，點選 `下一步`。
4. 在第 2 步（2/3），輸入 Apple ID，再輸入密碼。
5. 點選 `登入`。
6. 等待畫面顯示「登入 Apple（3／3）」。
7. 將 Apple 傳送的 6 位數驗證碼輸入 PinFly。
8. 輸入第 6 碼時會自動送出，也可以點選 `送出驗證碼`。
9. 畫面顯示「已登入」後，點選 `立即續簽` 或 `完成`。

Apple ID 與密碼只儲存在此 iPhone 的鑰匙圈，只傳送給 Apple。 〔待確認：獨立安全審查結果〕

> 請使用**安裝 PinFly 時的 Apple ID**。使用其他 Apple ID 登入時會顯示「此 Apple ID 與安裝 PinFly 的帳號不同」。

## 5.3 立即續簽

續簽有四個步驟，畫面會逐一顯示：

| 步驟 | 畫面文字 | 說明 |
|---|---|---|
| 1 | 連線至驗證伺服器 | 連線至協助登入的公開伺服器 |
| 2 | 登入 Apple | 以 Apple ID 登入 |
| 3 | 取得新的 7 天簽名 | 向 Apple 取得新的描述檔 |
| 4 | 安裝至手機 | 將描述檔安裝至 iPhone |

1. 開啟 PinFly，點選 `設定`。
2. 在「簽名」區，點選 `立即續簽`。
3. 等待四個步驟都顯示完成。
4. 畫面顯示「已續簽，簽名到 M/d HH:mm」即完成。

## 5.4 自動續簽

開啟 PinFly 時可自動續簽。

1. 開啟 `設定`。
2. 點選 `Apple 帳號與續簽`。
3. 開啟 `自動續簽` 開關。

規則：開啟 PinFly 時，若簽名剩不到 **3 天**即自動續簽，每 **6 小時**最多 1 次。Apple 暫時拒絕登入時，6 小時後再試。

## 5.5 首頁的剩餘天數

首頁上方的狀態列顯示簽名剩餘天數。

- 剩 3 天以上：不顯示提醒。
- 剩 2 天以內：「立即續簽」按鈕改為綠色。
- 剩不到 3 小時：首頁提示列顯示「續簽」按鈕。

## 5.6 續簽紀錄

在 `Apple 帳號與續簽` 頁面，可以看到「續簽紀錄（最近 5 筆）」，每筆紀錄顯示成功或失敗及原因。發生問題時，請記下時間與原因（第 8 章）。

## 5.7 僅有行動網路時的續簽

續簽分為下載與安裝兩個步驟，僅有行動網路時也能完成：

- **下載**：需要網路連線（行動網路亦可），不需要 LocalDevVPN。
- **安裝**：需要 LocalDevVPN 已連線。

安裝時的操作依網路狀態不同：

| 情況 | 操作 |
|---|---|
| 使用 Wi-Fi | 開啟 LocalDevVPN，回到 PinFly，點選 `安裝` 或 `安裝描述檔` |
| 僅有行動網路 | 關閉行動數據 → 開啟 LocalDevVPN → 點選 `安裝描述檔` → 完成後重新開啟行動數據 |

App 內說明寫的是「關閉行動數據」。 〔待確認：以「飛航模式＋Wi-Fi」完成安裝是否可行，請實機確認後再寫入本教學〕

安裝未完成時，畫面會顯示「描述檔已下載，尚未安裝」。不需要重新下載或登入，依上述步驟重新安裝即可。

## 5.8 登出與重設（一般不需要）

- `登出 Apple 帳號`：登出後需重新輸入密碼與驗證碼。若 Apple 拒絕重新登入，簽名到期後 App 將無法開啟。
- `重設驗證資料（adi.pb）`：僅在 Apple 持續要求重新驗證時使用。重設後需重新登入。

> 執行前請確認你記得目前的 Apple ID 與密碼。
