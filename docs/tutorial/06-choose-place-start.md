# 第 6 章：選地點與開始定位

**重點**：在首頁搜尋地名、貼上座標或 Google／Apple 地圖連結，或長按地圖新增地點。點選地點即前往該地點；點選「停止模擬」即回到真實位置。

## 6.1 首頁介紹

| 畫面位置 | 名稱 | 用途 |
|---|---|---|
| 上方 | 狀態列 | 顯示目前位置，例如「真實位置」或「在 …」 |
| 上方右角 | 設定（齒輪） | 進入設定頁 |
| 中間 | 地圖 | 長按可新增地點 |
| 搜尋欄 | 搜尋地點或貼上座標 | 輸入地名、座標或地圖連結 |
| 下方 | 地點列表 | 點選即前往該地點 |
| 地點列表旁 | 管理地點 | 改名、改範圍、隱藏、刪除 |
| 地點列表旁 | ＋ 新增地點 | 新增地點 |
| 底部 | 停止模擬 | 回到真實位置 |
| 底部 | 捷徑 | 執行捷徑，或開啟「捷徑」App |

![](images/guide_ch2_01.png)

*截圖說明：PinFly 首頁，上方狀態列、中間地圖、搜尋欄、下方地點列表與「停止模擬」按鈕，逐一標示。*

## 6.2 方法一：搜尋地名

1. 點選首頁的搜尋欄「搜尋地點或貼上座標」。
2. 輸入地名，例如「台北101」或「Tokyo Tower」。
3. 按鍵盤的搜尋鍵。
4. 在結果列表中點選地點。
5. 點選 `儲存地點`；不需儲存時點選 `僅前往`。

找不到時，App 會顯示：「找不到「…」。試試英文名稱，或長按地圖直接新增。」

![](images/guide_ch2_02.png)

*截圖說明：搜尋欄輸入「台北101」後的結果列表。*

## 6.3 方法二：貼上座標

1. 點搜尋欄。
2. 貼上「緯度, 經度」格式的座標，例如：`48.8584, 2.2945`（艾菲爾鐵塔）。
3. 按搜尋鍵。

> 緯度在 -90 到 90 之間，經度在 -180 到 180 之間。緯度與經度填反時，App 會提示「座標超出範圍」。

## 6.4 方法三：貼上 Google 或 Apple 地圖連結

1. 在 Google 地圖或 Apple 地圖點選「分享」，複製連結。
2. 回到 PinFly，將連結貼到搜尋欄。
3. 按搜尋鍵。

App 可以辨識的連結包括：Google 地圖的短網址（`maps.app.goo.gl`）、`goo.gl/maps` 開頭的網址，以及 Apple 地圖的 `maps.apple.com/p/…` 網址。 〔待確認：各種連結格式的實際涵蓋範圍〕

貼上連結需要網路連線。連結中找不到位置時，App 會顯示：「這個連結裡找不到位置。請改貼地點名稱，或長按地圖直接新增。」

![](images/guide_ch2_07.png)

*截圖說明：搜尋欄貼上 Google 地圖分享連結後，出現地點結果的畫面。*

## 6.5 方法四：長按地圖新增

1. 在地圖上長按目標位置。
2. 出現「新地點」卡片後，拖動地圖讓十字對準目標位置。
3. 在「地點名稱」輸入名稱（預設為「新地點」）。
4. 在「範圍」選擇 `小`、`中` 或 `大`。
5. 點選 `儲存地點`；不需儲存時點選 `僅前往`。
6. 放棄新增時，點選右上角 `×`。

![](images/guide_ch2_05.png)

*截圖說明：長按地圖後出現的「新地點」卡片，標示十字準心、地點名稱欄、範圍選項（小／中／大）與兩個按鈕。*

## 6.6 開始定位

1. 在下方地點列表中點選地點。
2. 地圖移至該地點，狀態列顯示「在 …」。
3. 第一次前往時，iPhone 會詢問位置權限。為了在鎖定螢幕或切換 App 時維持模擬，請先選擇 `使用 App 期間允許`，再選擇 `改為永遠允許`。 〔待確認：系統提示的確切選項文字〕
4. 也可以在搜尋結果點選 `儲存地點` 後，再點選列表中的地點。

尚未連線時，首頁會顯示提示，例如「無法連線」或「開發者映像未掛載」。請依第 8 章處理。

![](images/guide_ch2_06.png)

*截圖說明：點選地點後，狀態列顯示「在 …」，地點列表中該地點有標示。*

## 6.7 停止模擬

1. 點選底部的 `停止模擬`。
2. 不會顯示確認視窗，點一下即停止。
3. 螢幕上會出現「已回到真實位置，地圖約 10 秒內更新」。
4. 誤觸時，可於 10 秒內點選提示上的 `復原`。

停止後，Google 地圖等 App 約 10 秒後才會顯示真實位置。 〔待確認：室內 GPS 的實際延遲〕

![](images/guide_ch3_01.png)

*截圖說明：點選「停止模擬」後，畫面底部的提示「已回到真實位置」與「復原」按鈕。*

## 6.8 管理地點

1. 點地點列表旁的 `管理地點`。
2. 點選要修改的地點，可修改名稱、範圍，或移到地圖中心、隱藏、刪除。
3. 點選 `完成` 後才會儲存。
4. 刪除後，提示上會顯示 `復原`。

**備份地點**：在 `設定 › 進階 › 地點` 點選 `匯出地點`（存至「檔案」App 或傳送至電腦）。匯入地點檔會取代現有地點（按鈕顯示「匯入地點檔（取代目前 N 個）」），請先備份。

![](images/guide_ch4_02.png)

*截圖說明：「管理地點」頁面，點選一個地點後的編輯畫面（名稱、範圍、隱藏、刪除）。*
