# 第 6 章：選地點與開始定位

**先看這裡**：在首頁搜尋地名、貼座標、貼 Google 或 Apple 地圖連結，或長按地圖新增地點。點地點即可定位過去。按「停止模擬」即可回到真實位置。

## 6.1 首頁認識

| 畫面位置 | 名稱 | 用途 |
|---|---|---|
| 上方 | 狀態列 | 顯示目前在哪裡，例如「點下方地點開始模擬」 |
| 上方右角 | 設定（齒輪） | 進入設定頁 |
| 中間 | 地圖 | 長按可新增地點 |
| 搜尋欄 | 搜尋地點或貼上座標 | 輸入地名、座標或地圖連結 |
| 下方 | 地點列表 | 點一下就飛過去 |
| 地點列表旁 | 管理地點 | 改名、改範圍、隱藏、刪除 |
| 地點列表旁 | ＋ 新增地點 | 新增地點 |
| 底部 | 停止模擬 | 回到真實位置 |
| 底部 | 捷徑 | 執行捷徑，或打開「捷徑」App |

![](images/guide_ch2_01.png)

*截圖說明：PinFly 首頁，上方狀態列、中間地圖、搜尋欄、下方地點列表與「停止模擬」按鈕，逐一標示。*

## 6.2 方法一：搜尋地名

1. 點首頁的搜尋欄「搜尋地點或貼上座標」。
2. 輸入地名，例如「台北101」或「Tokyo Tower」。
3. 按鍵盤的搜尋鍵。
4. 在結果列表中點選要的地點。
5. 按 `＋ 存成地點` 存起來，或按 `只飛過去` 直接定位。

如果找不到，App 會提示：「找不到「…」。試試英文名稱，或長按地圖直接新增。」

![](images/guide_ch2_02.png)

*截圖說明：搜尋欄輸入「台北101」後的結果列表。*

## 6.3 方法二：貼上座標

1. 點搜尋欄。
2. 貼上「緯度, 經度」格式的座標，例如：`48.8584, 2.2945`（艾菲爾鐵塔）。
3. 按搜尋鍵。

> 緯度在 -90 到 90 之間，經度在 -180 到 180 之間。緯度與經度填反時，App 會提示「座標超出範圍」。

## 6.4 方法三：貼上 Google 或 Apple 地圖連結

1. 在 Google 地圖或 Apple 地圖按「分享」，複製連結。
2. 回到 PinFly，把連結貼到搜尋欄。
3. 按搜尋鍵。

App 可以辨識的連結包括：Google 地圖的短網址（`maps.app.goo.gl`）、`goo.gl/maps` 開頭的網址，以及 Apple 地圖的 `maps.apple.com/p/…` 網址。 〔待確認：各種連結格式的實際涵蓋範圍〕

貼連結需要網路。如果連結中找不到位置，App 會顯示：「這個連結裡找不到位置。請改貼地點名稱，或長按地圖直接新增。」

![](images/guide_ch2_07.png)

*截圖說明：搜尋欄貼上 Google 地圖分享連結後，出現地點結果的畫面。*

## 6.5 方法四：長按地圖新增

1. 在地圖上找到位置，長按。
2. 出現「新地點」卡片，拖動地圖，讓十字對準要的位置。
3. 在「地點名稱」輸入名字（預設是「新地點」）。
4. 在「範圍」選擇 `小`、`中` 或 `大`。
5. 按 `＋ 存成地點` 存起來，或按 `只飛過去` 直接定位。
6. 若不要了，按 `取消新增`。

![](images/guide_ch2_05.png)

*截圖說明：長按地圖後出現的「新地點」卡片，標示十字準心、地點名稱欄、範圍選項（小／中／大）與兩個按鈕。*

## 6.6 開始定位

1. 在下方地點列表中，點一下要的地點。
2. 地圖會飛到該地點，狀態列顯示「在 …」。
3. 第一次定位時，iPhone 會詢問定位權限。為了讓模擬在鎖螢幕或切換 App 時不中斷，請選擇 `使用 App 期間` 或 `永遠`。 〔待確認：系統提示的確切選項文字〕
4. 也可以按搜尋結果的 `＋ 存成地點` 後，再點列表的地點。

如果手機還沒連上，首頁會出現提示，例如「連不到手機」或「DDI 還沒掛載」。請依第 8 章處理。

![](images/guide_ch2_06.png)

*截圖說明：點地點後，狀態列顯示「在 …」，地點列表中該地點有標示。*

## 6.7 停止模擬

1. 按底部的 `停止模擬`。
2. 不會跳出確認視窗，按一下即停止。
3. 螢幕上會出現「已回到真實位置，地圖約 10 秒內更新」。
4. 若是誤按，在提示上的 `復原` 按鈕，可於 10 秒內復原。

停止後，Google 地圖等 App 約 10 秒後才會顯示真實位置。 〔待確認：室內 GPS 的實際延遲〕

![](images/guide_ch3_01.png)

*截圖說明：按下「停止模擬」後，畫面底部的提示「已回到真實位置」與「復原」按鈕。*

## 6.8 管理地點

1. 點地點列表旁的 `管理地點`。
2. 點選要改的地點，可以改名稱、改範圍、移到地圖中心、隱藏或刪除。
3. 按 `完成` 才會儲存。
4. 刪除後，提示上會有 `復原`。

**備份地點**：到 `設定 → 地點`，可以 `匯出地點`（存到「檔案」App 或傳到電腦）。匯入時會取代現有地點，App 會提示「匯入地點檔（取代目前 N 個）」，請先備份。

![](images/guide_ch4_02.png)

*截圖說明：「管理地點」頁面，點選一個地點後的編輯畫面（名稱、範圍、隱藏、刪除）。*
