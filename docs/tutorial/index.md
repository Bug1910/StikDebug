# PinFly 使用教學（給一般 iPhone 使用者）

PinFly 是一支免費、開源的 iPhone 定位模擬 App。它可以讓這支 iPhone 的定位顯示成你選的地點，例如台北101 或東京鐵塔。

- 授權：AGPL-3.0（原始碼公開，任何人可以看、可以改）。
- 安裝方式：不在 App Store 上架，要用「側載」安裝（把 App 直接裝到自己的 iPhone，不經過 App Store）。
- 語言：本教學以繁體中文為主。

> 本教學假設你**不是程式設計師**。遇到不熟的詞，請先看第 1 章的名詞表。

## 重要提醒

1. PinFly 只改**你自己的 iPhone** 的定位，請勿用於會違反當地法律或平台規定的用途。
2. 免費 Apple ID 簽的 App 只能用 **7 天**，到期後 App 會打不開。第 5 章說明如何續簽。
3. 停止模擬後，地圖約 **10 秒**內會回到真實位置。
4. 本教學中標示 〔待確認〕 的內容，表示尚未在實機上核對，請以 App 畫面實際文字為準。
