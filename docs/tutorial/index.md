# PinFly 使用教學（給一般 iPhone 使用者）

PinFly 是一支免費、開源的 iPhone 定位模擬 App。可將此 iPhone 的位置設為你選擇的地點，例如台北101 或東京鐵塔。

- 授權：AGPL-3.0（原始碼公開，任何人皆可檢視與修改）。
- 安裝方式：不在 App Store 上架，需以「側載」安裝（不經 App Store，直接將 App 安裝至 iPhone）。
- 語言：本教學以繁體中文為主。

> 本教學不需要程式背景。遇到不熟悉的名詞，請參閱第 1 章的名詞表。

## 重要提醒

1. PinFly 只變更**此 iPhone** 的位置，請勿用於會違反當地法律或平台規定的用途。
2. 以免費 Apple ID 簽名的 App 只能使用 **7 天**，到期後無法開啟。第 5 章說明如何續簽。
3. 停止模擬後，地圖約 **10 秒**內會回到真實位置。
4. 本教學中標示 〔待確認〕 的內容，表示尚未在實機上核對，請以 App 畫面實際文字為準。
