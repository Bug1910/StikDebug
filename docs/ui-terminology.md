# PinFly 介面用語規範

適用範圍：App 內所有畫面文字、通知、捷徑動作（App Intents）的標題與說明、Info.plist 權限說明、App 內「使用教學」、`docs/tutorial/*.md`。
新增或修改畫面文字前先查本表；表內沒有的概念，先補進本表再寫程式。

## 1. 原則

| 項目 | 規則 |
|---|---|
| 語氣 | 正式 App 用語，比照 iOS 系統繁體中文介面。不用口語、語助詞（喔、囉、啦、吧、呢）、驚嘆號、表情符號。 |
| 按鈕、標籤 | 2～4 字的動詞或名詞，例如「前往」「儲存地點」「立即續簽」。按鈕寫出按下後會發生什麼，不寫「好的」「開始使用」這類看不出結果的字。 |
| 說明句 | 一句一件事，完整但精簡，以句號結尾。不用「…一下」「先…再…就好」「通常就會過」這類口語結構。 |
| 人稱 | 不用人稱為原則；必要時用「你」，不用「您」。不寫「我們」「我幫你」。 |
| 動作動詞 | 介面元件一律「點選」；只有「長按」「按住拖動」與實體按鍵用「按」。App 與開關一律「開啟／關閉」，不用「打開／關掉」。 |
| 否定與失敗 | 用「無法」「尚未」「不需要」「失敗」，不用「沒辦法」「還沒」「不用」「沒成功」「讀不到」「存不進」「連不到」。 |
| 標點 | 全形標點；引用畫面上的名稱用「」；路徑用 ›（例：「設定 › 進階」）。數字與單位之間留半形空格（3 天、10 秒）。 |
| 一致性 | 同一個動作從按鈕到結果提示用同一個詞：按「儲存地點」→ 提示「已儲存」；按「停止模擬」→ 提示「已回到真實位置」。 |

## 2. 錯誤訊息格式

```
發生了什麼。下一步怎麼做。（錯誤 N）
```

- 第一句說結果，不道歉、不猜原因以外的事；第二句給一個可以立刻做的動作。
- 有錯誤代碼時放在句末括號，固定寫「錯誤」，不寫「代碼」「錯誤代碼：」。
- 例：「無法連線至手機的定位服務。請確認已連上 Wi-Fi 且 LocalDevVPN 已連線，再點選「重試」。（錯誤 9）」
- 失敗時簽名仍有效，補一句「目前的簽名到 M/d HH:mm 前仍可使用。」。

## 3. 用語對照表

每個概念只用一個正式用語。「禁用」欄的說法不得出現在畫面、捷徑說明與教學中（程式註解不受限）。

### 3.1 定位與移動

| 概念 | 正式用語 | 用法 | 禁用 |
|---|---|---|---|
| 瞬間到達某地點 | 前往 | 按鈕、捷徑動作 | 飛到、飛過去、定位過去、跳到、換到、傳送過去 |
| 不儲存、直接前往 | 僅前往 | 新地點卡片按鈕 | 只飛過去、直接定位、只去一次 |
| 沿途移動到某地點 | 移動 | 圖釘卡片按鈕 | 移動過去、走過去、自動行進、導航 |
| 沿途移動的功能與卡片標題 | 模擬移動 | 卡片標題、功能名稱 | 移動模式、自動走路 |
| 移動方式 | 路線／直線 | 分段控制 | 沿路、照道路走、直直走 |
| 交通方式 | 步行／單車／駕車／自訂 | 分段控制 | 走路、腳踏車、自行車、開車、汽車 |
| 移動中的控制 | 暫停／繼續／結束移動／停止模擬 | 按鈕 | 停下來、不走了、取消移動、回真實 |
| 在範圍內隨機走動 | 原地漫步 | 開關、狀態 | 亂走、閒晃、隨機走動 |
| 移動狀態提示 | 已抵達／已暫停／已改為直線 | 提示 | 到了、到囉、停住了 |
| 預排行程 | 開始行程／停止行程 | 按鈕 | 出發、跑行程、執行排程 |
| 手機目前的實際 GPS 位置 | 真實位置 | 狀態、提示 | 真的位置、原本位置、實際位置 |
| 送到手機的位置 | 模擬位置 | 狀態、說明 | 假定位、假位置、假的位置 |
| 正在送出模擬位置的狀態 | 模擬中 | 狀態列 | 定位中、假定位中 |
| 讓手機回到真實位置 | 停止模擬 | 按鈕、捷徑動作 | 停止定位、取消定位、回到真實 |
| 每次前往時實際選定的位置 | 落點 | 說明 | 降落點、著陸點 |
| GPS 輕微漂移的設定 | 位置微飄 | 設定開關 | 抖動、晃動、飄移模式 |

### 3.2 地點

| 概念 | 正式用語 | 用法 | 禁用 |
|---|---|---|---|
| 使用者儲存的位置 | 地點 | 清單、捷徑參數 | 景點、收藏、位置（位置只指座標） |
| 新增、修改、刪除 | 新增地點／編輯地點／刪除地點／管理地點 | 按鈕、頁面標題 | 加地點、改地點、刪掉 |
| 儲存 | 儲存地點／儲存變更／已儲存 | 按鈕、提示 | 存成地點、存起來、＋ 存成地點、存好了 |
| 落點範圍 | 範圍（小／中／大） | 分段控制 | 半徑、圈、圓圈、大小 |
| 範圍中心 | 中心 | 說明、捷徑結果 | 圓心 |
| 地點檔 | 地點檔 | 匯入、匯出 | places.json（僅限檔名說明時） |

### 3.3 連線與系統元件

| 概念 | 正式用語 | 用法 | 禁用 |
|---|---|---|---|
| PinFly 與手機定位服務之間的連線 | 連線 | 狀態、按鈕「重試」 | 通、接上、連到手機 |
| 連線失敗的狀態標題 | 無法連線 | 橫幅、提示 | 連不到手機、連不上、沒通 |
| 讓 PinFly 連線的 VPN App | LocalDevVPN | 一律寫全名 | VPN（單獨使用）、通道、本機連線、VPN 通道 |
| 系統的 VPN 設定頁 | VPN 與裝置管理 | 系統路徑 | 描述檔管理 |
| 連線用的金鑰檔 | 配對檔 | 匯入、狀態 | 鑰匙、通行證、pairing file |
| 尚未匯入配對檔 | 尚未配對 | 狀態標題 | 還沒配對 |

| 載入開發者映像 | 掛載 | 按鈕、狀態「已掛載／未掛載」 | 裝 DDI、載入 |
| 行動網路連線 | 行動網路 | 說明 | 4G、5G、數據網路 |
| iOS 的行動數據開關 | 行動數據 | 僅指系統開關或捷徑動作「設定行動數據」 | 4G 開關、數據 |
| iOS 飛航模式 | 飛航模式 | 系統用語 | 飛航、飛行模式 |

### 3.4 簽名與續簽

| 概念 | 正式用語 | 用法 | 禁用 |
|---|---|---|---|
| App 可使用的期限 | 簽名 | 「簽名到期」「簽名剩 N 天」 | 簽證、憑證、通行證 |
| 承載簽名的檔案 | 描述檔 | 下載、安裝、匯入 | 新簽名（指檔案時）、profile、通行證 |
| 換新 7 天簽名的動作 | 續簽 | 按鈕「立即續簽」「登入並續簽」、捷徑動作「續簽 PinFly」 | 重簽、刷新、Refresh、續約 |
| 把描述檔裝進手機 | 安裝描述檔 | 按鈕、狀態「描述檔已下載，尚未安裝」 | 裝上、裝上新簽名、裝好 |

| 產生 Apple 驗證資料的第三方伺服器 | 驗證伺服器 | 說明；括號補「anisette」僅限進階頁 | anisette（單獨使用）、幫忙登入的伺服器 |
| 驗證伺服器的本機資料 | 驗證資料 | 進階頁 | adi.pb（僅限括號補充） |

### 3.5 捷徑、引導與教學

| 概念 | 正式用語 | 用法 | 禁用 |
|---|---|---|---|
| iOS 捷徑 App | 「捷徑」App | 指 App 時加引號 | Shortcuts、捷徑程式 |
| 使用者建立的一組動作 | 捷徑 | 「執行捷徑「出門改定位」」 | 一鍵、腳本 |
| PinFly 提供給捷徑的動作 | 捷徑動作 | 說明 | Intent、按鈕 |
| 自動觸發的捷徑 | 自動化 | 系統用語 | 排程、定時任務 |
| 第一次開啟時的檢查清單 | 使用引導 | 設定項目、頁面標題 | 新手教學、導覽、開箱 |
| 依章節查閱的說明 | 使用教學 | 設定項目、頁面標題 | 說明書、手冊、FAQ |

### 3.6 系統標準按鈕（比照 iOS 繁體中文）

| 用途 | 用語 | 禁用 |

| 確認訊息、關閉提示 | 好 | 知道了、OK、了解 |
| 結束編輯並保留 | 完成 | 好了、確定（編輯頁） |
| 放棄操作 | 取消 | 算了、不要了 |
| 進入下一頁、略過一步 | 下一步／上一步／略過 | 往下、跳過 |

| 稍後處理 | 稍後 | 等一下、晚點 |

## 5. 檢查方式

提交前搜尋下列字樣，畫面字串中不應出現：

```
飛到|飛過去|只飛|存成地點|假定位|還沒|沒成功|不用|讀不到|存不進|連不到|連不上|裝上|知道了|再試一次|圓心|打開|搞|喔|囉|啦|！
```

例外：引用 iOS 系統畫面原文（例如 LocalDevVPN 的「已中斷連線」）、使用者自建捷徑名稱（「出門改定位」）。
